# Security

This repository is the source of [hirokuwana.com](https://hirokuwana.com),
including its public tool API (`/api`). Only the latest deployed version on the
default branch is supported.

## Reporting a vulnerability

Please report privately through the contact form at
https://hirokuwana.com/#contact. Do not open a public issue for a security
problem. Include what you found, where (URL or file path), and steps to
reproduce.

Please do not run load tests or automated scanners against the live site or
API, and do not access or change data that is not yours.
