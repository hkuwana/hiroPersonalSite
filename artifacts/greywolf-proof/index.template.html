What this example does—and what it hasn’t proved

This is a small, working example built with AI-assisted code. A deterministic parser reads this specific filing’s first net-sales table; it is not a general-purpose document-extraction model. The nine-month Services value is deliberately selected to test period matching and reconciliation. It is not an observed model error.

Public Apple data only. This is illustrative work for discussion, not Greywolf client work or an investment recommendation. Matching these figures proves the stated checks for this example; it does not establish the accuracy of a wider workflow. No form submissions, analytics, storage or background network requests are used.
