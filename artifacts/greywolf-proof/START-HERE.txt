GREYWOLF × OTTERD — A SMALL WORKING EXAMPLE

Watch greywolf-working-proof.mp4 for the 20-second visual proof.
Open index.html in a browser to inspect the example. It works offline.

Try it
1. Select "Try the numbers yourself".
2. Click any value to highlight its location in the original source excerpt.
3. Select "Try the wrong period". Services changes from the three-month
   value of 27,423 to the nine-month value of 80,408. Both figures are from
   Apple's public filing. The wrong selection is a deliberately seeded test.
4. The period check fails and the component total differs by 52,985 million.
5. Select "Use the quarter". The three quarterly figures reconcile again.
6. Export the current selection to CSV, or open the checked Excel example.
   In Excel, change C5 from 3 to 9 and back to reproduce the same test.

What is real
- Public Apple FY25 Q3 Form 10-Q, printed statement page 1 / PDF page 4.
- Source values are extracted by code from the downloaded filing.
- The browser example and film use the same source records and check logic.
- The Excel workbook uses formulas and source hyperlinks; its Services-period
  selector recalculates the result.

What this does not claim
- No Greywolf positions, research notes, reports or private files are used.
- This is an illustrative example, not delivered Greywolf client work.
- The wrong-period selection is staged, not an observed AI model mistake.
- The parser was written with AI assistance for this particular filing.
  This does not demonstrate general extraction accuracy across documents.
- The movie is a scripted execution with animated transitions, not a claim
  about extraction speed. Its worksheet illustration represents the same
  source values and logic as the companion workbook; it is not an Excel
  screen recording.
- No forms, analytics, storage or background network requests are used.
  Clicking the original source link opens the public filing externally.
